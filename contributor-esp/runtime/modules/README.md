# Módulos de runtime

Las escenas importan estos módulos del runtime para comunicarse con el Explorer y acceder a las funciones del entorno.

- [API del motor](engine-api.md): sincronización de entidades y componentes.
- [Jugadores](players.md): información sobre los jugadores conectados.
- [Identidad de usuario](user-identity.md): información del usuario actual.
- [Acciones restringidas](restricted-actions.md): acciones sujetas a los permisos de la escena.
- [Signed Fetch](signed-fetch.md): solicitudes HTTP firmadas.
- [Runtime (inglés)](../../../contributor/runtime/modules/runtime.md): información del entorno de ejecución y de la escena.
