# Publish

Publishing a scene for mobile follows the **same process as any other scene** — deploy via the Creator Hub or the CLI as described in the [Publishing](../../sdk7/publishing/publishing.md) guide. The pages in this section cover what’s specific to mobile on top of that standard flow.

{% hint style="info" %}
If you haven’t published your scene yet, start with [Publishing](../../sdk7/publishing/publishing.md) under Scenes (SDK7). The steps below apply once your scene is already live.
{% endhint %}

- [Get featured](get-featured.md): How to get your scene featured in the mobile Discover section.
- [iOS curation](ios-curation.md): How iOS content curation works and how to submit your scene or world for review.
