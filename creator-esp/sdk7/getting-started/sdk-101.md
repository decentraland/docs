# SDK Quick Start

El SDK de Decentraland es una herramienta poderosa que te permite crear o mejorar tus scenes escribiendo código en Typescript (Javascript + Tipos).

{% hint style="info" %}
**💡 Tip**: Si prefieres crear tus scenes solo con herramientas no-code, consulta [Scene Editor](../get-started/about-editor.md).
{% endhint %}

Este tutorial te guía en cómo configurarte y te muestra los conceptos básicos para escribir código en una scene de Decentraland.

## Instalar el Creator Hub

El Creator Hub te permite construir, previsualizar y desplegar scenes de Decentraland. Descarga el Creator Hub [aquí](https://decentraland.org/download/creator-hub).

Para editar el código de tu scene, también debes instalar [Visual Studio Code](https://code.visualstudio.com/), si aún no lo tienes.

Lee la [Guía de instalación](../get-started/editor-installation.md) para más detalles sobre la instalación del Creator Hub.

## Crea tu primera scene

Para crear tu primera scene, sigue estos pasos.

1. Abre el Creator Hub.
2.  Selecciona la pestaña **Scenes**, y haz clic en **Create Scene**.

    ![](../images/editor/create-scene.png)
3. Luego puedes elegir entre diferentes plantillas de inicio. Para este ejercicio, elige la **Empty Scene**.

Este paso puede tomar un par de minutos. Puebla tu carpeta con el conjunto predeterminado de archivos para una scene básica.

Una vez hecho esto, verás la cuadrícula vacía de tu scene.

## Agregar ítems de los asset packs

Explora los **Asset packs** en la sección inferior del Scene Editor, suelta un par de ítems y ajusta sus posiciones. Para los fines de este tutorial, cualquier ítem servirá por ahora.

![](../images/editor/asset-packs.png)

Para colocar un ítem, haz clic y arrástralo desde el menú de asset pack a una ubicación en tu scene en el canvas.

![](../images/editor/drop-item.gif)

Los ítems ya colocados se pueden hacer clic y arrastrar para reposicionarlos libremente. Consulta [Scene editor essentials](../get-started/scene-editor-essentials.md#position-items) para más detalles.

{% hint style="info" %}
**💡 Tip**: Cubre toda la scene con un ítem de suelo. Los ítems de tipo **Ground** tienen un ícono de cubo de pintura. Si arrastras uno de estos a tu scene, cubre todo el suelo de tu scene con copias de este ítem.

<img src="https://github.com/decentraland/docs/blob/main/images/editor/ground.png" alt="Ground" data-size="original">
{% endhint %}

## Ejecutar un preview

Haz clic en el botón **Preview** en el menú superior para cargar tu scene dentro de Decentraland. Ahora puedes explorar la scene como un avatar de Decentraland.

![](../images/editor/running-preview.png)

Lee más sobre el preview de scene en [preview a scene](preview-scene.md).

{% hint style="info" %}
**💡 Tip**: Puedes mantener la ventana de preview abierta mientras sigues trabajando en tu scene, y se actualizará cada vez que hagas un cambio en el Scene Editor.
{% endhint %}

## Editar el código de la scene

Las siguientes secciones describen cómo puedes editar el código de tu scene, dándote mucha más libertad como creador.

Haz clic en el botón **<> Code** en el menú superior para abrir tu proyecto de scene en Visual Studio Code.

![](../images/editor/code-button.png)

{% hint style="warning" %}
**📔 Nota**: Instala [Visual Studio Code](https://code.visualstudio.com/), si aún no lo tienes.
{% endhint %}

Esto abre una ventana separada con Visual Studio Code. En el margen izquierdo puedes navegar la estructura de archivos y carpetas de tu proyecto.

![](../images/editor/files-on-vs-studio.png)

Abre el archivo `index.ts` desde dentro de la carpeta `src` en tu scene. Su contenido debería verse así:

```ts
import {} from '@dcl/sdk/math'
import { engine } from '@dcl/sdk/ecs'

export function main() {}
```

Las primeras dos líneas tratan con declaraciones `import`. Estas obtienen referencias a cosas que están definidas en otros archivos, para que puedan usarse en este archivo. No necesitarás tratar con estas líneas directamente en este tutorial, pero nota que la lista de cosas que se obtienen crecerá a medida que escribas tu código.

Observa que este archivo define una función llamada `main()`. Esta función es el punto de entrada a la scene, cualquier código que pongas allí se ejecutará cuando la scene se cargue por primera vez. Si escribes líneas de código fuera de esta función, nunca se ejecutarán.

En la sección anterior mostramos cómo puedes arrastrar fácilmente el modelo 3D de aguacate personalizado a tu scene de manera no-code. Ahora agregaremos un segundo aguacate, para ver cómo lograr lo mismo escribiendo código.

Reemplaza el contenido completo de tu archivo `index.ts` con lo siguiente. Estas líneas expanden la función `main()` y agregan un par de imports:

```ts
import { Vector3 } from '@dcl/sdk/math'
import { engine, Transform, GltfContainer } from '@dcl/sdk/ecs'

export function main() {
	// create a fresh new Entity
	let avocado2 = engine.addEntity()

	// give it a Transform
	Transform.create(avocado2, {
		position: Vector3.create(8, 0, 8),
	})

	// give it a GLTF
	GltfContainer.create(avocado2, {
		src: 'assets/scene/avocado.glb',
	})
}
```

Si abres el preview de la scene nuevamente, ahora deberías ver dos aguacates: el que agregaste en el Scene Editor y el que agregaste via código.

![](../images/editor/avocados.png)

Las líneas que acabas de agregar crean una nueva [entity](../architecture/entities-components.md), le dan una [forma](../3d-essentials/shape-components.md) basada en el modelo 3D que descargaste, y [establecen su posición y escala](../3d-essentials/entity-positioning.md) a través del **Transform**.

Ahora vuelve al Scene Editor y selecciona el primer aguacate que agregaste. En el panel de propiedades para este ítem verás que la UI para los componentes Transform y GLTF muestra la misma información que en el código que acabas de escribir.

![](../images/editor/avocado-components.png)

## Agregar interactividad

Para hacer tu scene más atractiva, hagamos que las entities en la scene respondan a las interacciones del jugador.

Al final de la función `main()` (antes de que se cierre con el último **}**), agrega un manejador de eventos de puntero a la entity de aguacate. Esto ejecuta una función personalizada cada vez que el jugador hace clic en el aguacate.

```ts
pointerEventsSystem.onPointerDown(
	{
		entity: avocado2,
		opts: { button: InputAction.IA_POINTER, hoverText: 'Collect' },
	},
	function () {
		console.log('CLICKED AVOCADO')
	}
)
```

{% hint style="info" %}
**💡 Tip**: Visual Studio Code te ayuda marcando errores de sintaxis, autocompletando mientras escribes e incluso mostrando sugerencias inteligentes que dependen del contexto. También puedes hacer clic en un objeto para ver la definición completa de su clase.

Si alguna de las palabras que pegaste está subrayada en rojo, pasa el cursor sobre ellas para ver si VS Studio ofrece una solución fácil. Probablemente tendrás que hacer esto para **pointerEventsSystem** e **InputAction**.

Hacer clic en la bombilla sugerirá `Update import from @dcl/sdk/ecs`. Selecciona esta opción para agregar imports al inicio de tu archivo `index.ts`.
{% endhint %}

La declaración `pointerEventsSystem.onPointerDown()` define tres cosas:

* Qué `entity` funciona con los eventos de puntero.
* Un objeto `opts` con parámetros adicionales opcionales. En este caso incluimos qué botón usar y qué texto de sugerencia mostrar.
* Una función, que se ejecutará cada vez que se haga clic en la entity.

En este caso, la función que estamos ejecutando es muy simple. Tiene solo una línea de largo y simplemente imprime algo de texto en la consola.

```ts
console.log('CLICKED AVOCADO')
```

En la sección `opts`, estamos configurando el campo `button` para que escuche el botón de puntero (el botón izquierdo del mouse en una PC). También estamos configurando el parámetro `hoverText` para mostrar texto personalizado. De esa manera los jugadores leerán el texto "collect" cuando pasen el cursor sobre el aguacate, y sabrán qué sucederá si hacen clic en él. El aguacate no hace mucho todavía, pero llegaremos allí en los próximos pasos.

Para ver ese mensaje que el evento de clic está registrando, necesitarás abrir la consola. Para hacer esto, abre el preview de la scene nuevamente si aún no lo tienes ejecutándose, y presiona la tecla **\`** para alternar la visualización de la consola. Ahora cada vez que hagas clic en el aguacate que agregaste via código, verás:

![](../images/editor/logs-avocado.png)

\{% hint style="warning" %\} **📔 Nota**: Para que una entity sea clickeable, debe tener una geometría de collider. El modelo usado aquí ya incluye uno. Consulta la sección [Colliders](../3d-modeling/colliders.md) para soluciones alternativas para modelos que no incluyen una geometría de collider. \{% endhint %\}

Ahora hagamos que esa función de clic haga algo más interesante, hagamos que el aguacate desaparezca. Usa \`

engine.removeEntity()\` para deshacerte del aguacate una vez que se haga clic. Agreguemos una línea extra a nuestro snippet:

```ts
pointerEventsSystem.onPointerDown(
	{
		entity: avocado2,
		opts: { button: InputAction.IA_POINTER, hoverText: 'Collect' },
	},
	function () {
		console.log('CLICKED AVOCADO')
		engine.removeEntity(avocado2)
	}
)
```

Ahora cuando se hace clic, el aguacate desaparece de tu scene.

## Tweens

Los tweens describen una transición gradual de una posición/rotación/escala a otra, durante un período de tiempo.

Comencemos agregando un tween de escala a nuestro aguacate, solo para probar la característica. Agrega las siguientes líneas dentro de la función `main()`, al final, sin cambiar nada de lo que ya agregaste:

```ts
export function main() {
	// Code from previous snippets (do not change)
	// (...)

	// New code:
	Tween.setMove(avocado2, 
		Vector3.create(3, 0, 3), 
		Vector3.create(8, 0, 8), 
		5000
	)

}
```

{% hint style="info" %}
**💡 Tip**: Al pegar esto, puedes encontrar más palabras subrayadas en rojo debido a imports faltantes.

Pasa el cursor sobre cada una y haz clic en la bombilla, sugerirá `Update import from @dcl/sdk/ecs`. Selecciona esta opción para agregar imports al inicio de tu archivo `index.ts`.
{% endhint %}

El componente `Tween` que creamos tiene argumentos que lo hacen cambiar de posición, desde una posición en las coordenadas _3,0,3_ de la scene, a las coordenadas _8,0,8_, durante un período de 5000 milisegundos (5 segundos). Este movimiento comenzará tan pronto como comience la scene.

Una función `Tween` setMove requiere la siguiente información:

* `entity`: En qué entity trabajar
* `start`: Posición inicial.
* `end`: Posición final.
* `duration`: Duración (en milisegundos) del escalado de inicio a fin.

Este otro parámetro opcional también está disponible:

* `easingFunction`: Qué tipo de curva usar para controlar la tasa de cambio a lo largo del tiempo. En este caso usamos linear, lo que resulta en un cambio constante suave.

Podemos jugar con el parámetro `easingFunction` para obtener algunos efectos interesantes. Por ejemplo podemos usar `EF_EASEINBOUNCE` para realizar la transición usando una interpolación ease-in bounce, que comienza con un efecto rebotante y luego va de lento a rápido.

{% hint style="info" %}
**💡 Tip**: También puedes usar el componente **Tween** para escalar o rotar una entity durante un período de tiempo, ¡esta es una herramienta realmente útil! Aprende más [aquí](../3d-essentials/move-entities.md)
{% endhint %}

## Usando tus propias funciones

En esta sección agregaremos otro tween en la escala del Aguacate, para hacer que el efecto de desaparición se vea más atractivo. Pero tomaremos un enfoque ligeramente menos directo para introducir algunos otros conceptos.

La forma más simple de hacer que nuestro aguacate se encoja cuando hacemos clic en él es agregar un tween dentro de la función de eventos de puntero, en lugar de la línea `engine.removeEntity(avocado2)`. Pero en su lugar, creemos este tween en una función separada que luego podamos reutilizar para otros ítems. ¡De esa manera no necesitaremos escribir el mismo código dos veces! Nuestra nueva función será separada de `main()`, por lo que no hará nada por sí sola, pero pronto la estaremos llamando.

```ts
function collect(myEntity: Entity) {

	Tween.setScale(myEntity, 
		Vector3.One(), 
		Vector3.Zero(), 
		500,
		EasingFunction.EF_EASEINBOUNCE
	)
}
```

Nota que el tween se agrega a una entity llamada `myEntity`, en lugar de `avocado2`. `myEntity` es realmente un marcador de posición, no hay ninguna entity llamada así en la scene. Viene de un parámetro definido en la función. Cuando llames a la función `collect()`, puedes pasar cualquier entity en la scene, y le aplicará un `Tween`. Más sobre eso más tarde.

{% hint style="info" %}
**💡 Tip**: Siempre que haya código que podrías estar usando múltiples veces en tu scene, es una buena práctica ponerlo dentro de una función. De esa manera solo tienes que escribirlo una vez, y es más fácil de mantener.
{% endhint %}

Aquí creamos un Tween que afecta la _Scale_, así que ahora `start` y `end` se refieren al tamaño del aguacate, no a la posición. Va de un tamaño de uno a cero, durante una duración de 500 milisegundos (medio segundo), y usa una función de easing `EASEINBOUNCE`, que le da un efecto rebotante divertido.

Ahora modifiquemos la función que escribimos para cuando hacemos clic en el aguacate. Cambiemos la línea que dice `engine.removeEntity(avocado)`, y en su lugar llamemos a la función `collect()` que acabamos de definir, pasando una referencia a nuestra entity de aguacate:

```ts
pointerEventsSystem.onPointerDown(
	{
		entity: avocado2,
		opts: { button: InputAction.IA_POINTER, hoverText: 'Collect' },
	},
	function () {
		console.log('CLICKED AVOCADO')

		collect(avocado2)
	}
)
```

Si ahora abres el preview de la scene y haces clic en el aguacate, deberías verlo irse con estilo, realizando un movimiento divertido saltarín.

{% hint style="warning" %}
**📔 Nota**: Puede que hayas descubierto que ahora el aguacate se encoge a un tamaño de 0, pero aún existe. No cubriremos esto en este primer tutorial, pero en un escenario ideal deberías asegurarte de eliminar la entity después de que el tween termine, para optimizar el rendimiento de tu scene. Consulta [On tween finished](../3d-essentials/move-entities.md#on-tween-finished).
{% endhint %}

## Referenciar un ítem del Scene Editor

Tu código también puede hacer cosas con los ítems que agregaste visualmente en el Scene Editor. Puedes obtener estos ítems por nombre en tu código, usando la función `engine.getEntityOrNullByName()`. Usa el nombre para el ítem que ves escrito en el [árbol de entities](../get-started/scene-editor-essentials.md#the-entity-tree).

En este ejemplo, tenemos una entity llamada **Yellow Crate**. Puedes usar cualquier ítem que desees, solo asegúrate de escribir su nombre exactamente como en el árbol de entities.

{% hint style="info" %}
**💡 Tip**: Puedes renombrar entities haciendo clic derecho y seleccionando **Rename** en la entity en el árbol de entities.
{% endhint %}

![](../images/editor/asset-packs.png)

```ts
export function main() {
	// Avocado stuff

	const crate = engine.getEntityOrNullByName('Yellow Crate')

	if (crate) {
		console.log('The crate exists')
	}
}
```

En el snippet anterior, usamos `engine.getEntityOrNullByName()` para obtener una referencia a una entity llamada _Yellow Crate_. En la siguiente línea, hacemos `if (crate)` para asegurarnos de que realmente haya una entity con este nombre en la scene. Si no la hay, entonces el valor de `crate` será `null`. Consulta [Reference Items](../code/reference-items.md) para más información.

{% hint style="info" %}
**💡 Tip**: Todas las entities agregadas via el Scene Editor ya estarán cargadas en tu scene para cuando el código en la función `main()` sea llamado. Debería ser seguro referenciarlas en esta función, o en otras funciones que son llamadas indirectamente por ella.
{% endhint %}

Ahora agreguemos un comportamiento de puntero a nuestra entity Yellow Crate, justo como lo hicimos con el aguacate.

```ts
export function main() {
	// Avocado stuff

	const crate = engine.getEntityOrNullByName('Yellow Crate')

	if (crate) {
		console.log('The crate exists')

		pointerEventsSystem.onPointerDown(
			{
				entity: crate,
				opts: { button: InputAction.IA_POINTER, hoverText: 'Collect' },
			},
			function () {
				console.log('CLICKED CRATE')
				collect(crate)
			}
		)
	}
}
```

Nota cómo estamos llamando a la función `collect()` que definimos antes. ¡Dado que la función está definida por separado, solo necesitábamos escribir esa línea para llamarla!

{% hint style="info" %}
**💡 Tip**: También puedes obtener [Smart Items](../interactivity-1/smart-items.md) de tu scene de la misma manera, y hacer lo que quieras con ellos via código. Consulta [Reference Items](../code/reference-items.md) para más información.
{% endhint %}
