# Slay the Steps

Study a Studio-made, authoritative multiplayer experience built for Decentraland Festive Trail 2025. It includes custom avatars, Marketplace API integration, and a custom colour-wheel picker. Its code separates client, server, and shared modules, and includes the source assets alongside the deployable scene.

Play it in the [Slay the Steps World](https://play.decentraland.org/?realm=slaythesteps.dcl.eth).
